Plan honest-cv

Un servidor MCP, una CLI y una skill de Claude Code que convierten tu experiencia real en CVs aptos para ATS, adaptados a cada tipo de puesto, sin inventar nada.

Objetivo

Publicar en unas 2 semanas una v0.1 que cualquier persona pueda instalar en una línea y usar desde Claude Code o Cursor. Debe resolver tres cosas:

  1. Inventario honesto: una entrevista guiada registra cada skill con su nivel de evidencia y sus años.
  2. Variantes por puesto: genera PDF y DOCX aptos para ATS desde una sola fuente de datos.
  3. Análisis contra una vacante: mide la cobertura y explica qué falta y por qué.

Una meta secundaria pesa igual: que el repo sea tu mejor demostración de diseño MCP, agentes con guardrails y herramientas internas para desarrolladores.

Qué lo hace distinto

  • La honestidad la aplica el sistema. Cada skill lleva un nivel: P (producción), L (proyecto propio), F (familiaridad) o X (no la tiene). Una F sale etiquetada como "Familiarity" y una X nunca aparece. El agente no puede subir de nivel una skill sin que la persona lo confirme.
  • El análisis de brechas usa tu propio inventario. No basta con decir "te falta Spring JDBC". La herramienta distingue tres casos: la tienes en P pero no está en este CV, la tienes en F, o no la tienes.
  • El servidor no necesita API key. Es determinista. El LLM del cliente (Claude o Cursor) extrae las palabras clave de la vacante y conduce la entrevista, y el servidor valida, genera y mide.
  • Las garantías de ATS se comprueban. Una sola columna, sin ligaduras, orden de lectura igual al del DOM y texto que se puede extraer. Cada build se verifica con pypdf y pdfminer.

Riesgos

  • Fuga de datos personales: usar un repo nuevo, poner profiles/ en .gitignore y usar solo el perfil ficticio en tests y demos.
  • Dependencia de Chrome: puede romper la instalación en una línea. Se mitiga con el spike de Typst.
  • Competencia establecida: no se compite en plantillas bonitas. El argumento es MCP, honestidad y brechas.
  • Que se alargue: todo lo que no está en la tabla "Entra" espera a la v0.2.

Cómo saber si funcionó

  • El autor lo usa para sus propias postulaciones.
  • Está publicado en PyPI, en el registro de MCP y en awesome-mcp-servers.
  • Meta realista: 100–300 estrellas el primer mes. Puede ser más si el lanzamiento pega en HN o Reddit.
